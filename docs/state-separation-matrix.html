Pemisahan Client UI State vs Server State

Laporan

Matriks analisis pemisahan state

Dokumen ini memetakan seluruh variabel state ke kategori Client UI State dan Server State. Pendekatan ini menjaga UI interaktif tetap responsif, sementara data API dikelola dengan cache dan invalidasi query agar konsisten.

Variabel State Kategori Teknologi Alasan
activeModal Client UI State Zustand Status modal hanya berlaku pada sisi antarmuka dan tidak perlu dipersisten ke server.
activeTab Client UI State Zustand Tab aktif mengubah tampilan UI lokal tanpa memerlukan fetch backend.
theme Client UI State Zustand Tema antarmuka adalah konfigurasi UI yang berubah cepat dan bersifat lokal.
draftStep Client UI State Zustand Langkah draft form hanya relevan untuk alur pengerjaan UI sebelum kirim ke server.
assessment list Server State TanStack Query Data berasal dari REST API dan perlu cache, stale time, serta invalidation saat mutasi berlangsung.
course catalog Server State TanStack Query Data katalog relatif stabil, cocok dengan staleTime lebih lama dan cache yang dipertahankan.
create/update/delete assessment Mutation State TanStack Query Perubahan data harus mengubah server state lalu memicu invalidasi cache agar UI otomatis diperbarui.
