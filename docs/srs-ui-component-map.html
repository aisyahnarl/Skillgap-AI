Pemetaan Kebutuhan SRS ke Komponen UI

Dokumen ini memetakan kebutuhan utama pada SRS proyek SkillGap.AI ke komponen antarmuka yang telah dibuat. Pengembangan dilakukan dengan pendekatan modular, state-driven, dan validasi client-side agar frasa kebutuhan dapat diwujudkan sebagai UI yang reusable dan mudah dipelihara.

SRS-04 Data list memungkinkan pencarian dan filter Data table/list module list.html, app.js Selesai

SRS-07 Analisis performa dan kontrol re-render Performance card module dashboard.html, app.js Monitoring

Modul 1

Dashboard Module

Menampilkan KPI utama, trend, dan ringkasan performa user agar ada gambaran cepat terhadap hasil assessment.

Modul 2

Form Entry Module

Memvalidasi input wajib, memilih minat user, dan menyiapkan data rekomendasi agar input tidak kosong atau ambigu.

Modul 3

Data Table/List Module

Mengelola data profil, filter, pencarian, dan status validasi sehingga user dapat memantau daftar secara ekspresif.
